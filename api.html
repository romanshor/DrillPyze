DrillPyze

DrillPyze: a coupled axial-torsional drillstring dynamics simulator, torque & drag model and controller test bench. SI units throughout.

Case files and builder (config)

Case configuration: a plain, JSON-serialisable description of a simulation case in SI units, and a builder that turns it into a Simulation.

The same structure is used by the user interface, scripts and (later) the data-driven agent, so a case can be saved, shared and reproduced:

from DrillPyze import config
cfg = config.well_a()                 # the example case
cfg['parameters']['friction']['mu_static_open'] = 0.5
sim = config.build(cfg)               # initialised Simulation
config.save(cfg, 'case.json')
DrillPyze.config.well_a()[source]

Synthetic Well A of Aarsnes & Shor (2018): vertical to 1500 m, build at 3 deg/30 m to 60 deg, then tangent; 230 m of 5-3/4” collars below 5” drill pipe; bit off bottom at 2500 m. Friction gives off-bottom stick-slip with a stiff top-drive controller.

Simulation (simulation)

User-facing simulator for the coupled axial-torsional drillstring model.

Workflow:

sim = Simulation(wellbore, drillstring, fluid, params)   # set up
sim.initialize(bit_depth=3000.0, hole_depth=3005.0)        # initialise
sim.step(5.0, omega_sp=60 * units.RPM)                     # step ...
sim.step(1.0, v_block=0.01)                                # ... and step again
df = sim.results()                                         # recorded data

The simulation can be paused between step calls for as long as needed, inputs can change between calls, and calls of any length give identical results to one long call. This is the hook for live data streaming and for controllers written in Python (call step at the controller sample rate with motor_torque=...).

damping_summary(frequency=None)[source]

Predicted modal damping ratios per component and direction, at the reference frequency (default) or at frequency (Hz):

zeta_fluid = (k0 + k1_stokes H) / (2 omega) * s, H = 1/(1 + (f_c/f)^2) zeta_material = alpha H / (2 omega) + beta omega / 2 (Rayleigh / Kelvin-Voigt) zeta_numerical = pi f dx (1 - nu) / c (first-order Godunov)

with s = 1 at f_ref (the model’s frequency-independent Stokes coefficient). zeta_fluid_true scales the Stokes part by sqrt(f/f_ref) as the physical layer would.

step(duration, omega_sp=None, v_block=None, motor_torque=None, omega_td=None, wob_sp=None, flow_rate=None, inlet_temperature=None)[source]

Advance the simulation by duration seconds with inputs held constant. Inputs not given keep their previous values.

Top drive (choose one; the most recently given one sets the mode):

omega_sp speed set point (rad/s) for the internal controller motor_torque motor torque (N m) from an external controller omega_td prescribed top-drive speed (rad/s), e.g. measured RPM

Drawworks (choose one):

v_block block velocity (m/s, positive lowering) wob_sp WOB set point (N) for the autodriller

Circulation (hydraulics and wellbore temperature):

flow_rate pump rate (m^3/s) inlet_temperature mud temperature entering the drillstring (C)

Inputs without a controller (prescribed speed, block velocity, pump rate, inlet temperature) approach a new value linearly over a short ramp time (params.ramps; 0 = instant), starting from the current value – or, when taking over from another mode, from the present physical value. Controlled set points (omega_sp, wob_sp) are not ramped by default: the controller shapes the response.

Returns a dict of the latest scalar values.

class DrillPyze.parameters.DampingParameters(k_t=0.0, k_a=0.0, fluid=True, loss_factor=0.01, reference_frequency_axial=None, reference_frequency_torsional=None, high_pass_fraction=0.25, yield_drag='pumps_off', max_frequency=10.0)[source]

Bases: object

Distributed damping (docs/derivation/README.md, sec. 5.6).

Fluid (F1, from the mud and the string/hole geometry, no free parameter):

steady annular Couette drag on the full velocity, plus Stokes-layer drag sqrt(rho mu omega_ref / 2) on the inner and outer walls acting on the oscillatory part of the velocity (high-passed below high_pass_fraction * omega_ref). omega_ref defaults to the first (quarter-wave) mode of the string, axial and torsional separately.

Fluid (F2): Bingham yield-stress drag tau_y * pi * OD per length, added to the

Coulomb wall friction; applied per yield_drag.

Material (M1): Rayleigh damping zeta(f) = alpha/(2 omega) + beta omega/2 fitted so

zeta = loss_factor/2 at f_ref and at max_frequency (and below it in between); beta is Kelvin-Voigt strain-rate damping sigma = E (eps + beta deps/dt), alpha acts on the oscillatory velocity.

Calibration: k_t, k_a are additional mass-proportional rates (1/s) on the

full velocity (the original lumped model), default 0.

Validity: the fluid terms are evaluated at a single reference frequency, so modes above it are under-damped by sqrt(f / f_ref); together with the numerical dissipation of the first-order scheme this limits the model to vibrations below max_frequency (10 Hz).

class DrillPyze.parameters.BitParameters(model='coulomb', mu_static=0.6, mu_kinetic=0.4, drilling_strength=50000000.0, zeta=0.8, contact_wob=0.0, blades=5, radius=None, strength_source='constant', cutting_efficiency=1.0, nozzle_area=0.00035628, discharge_coefficient=0.95)[source]

Bases: object

Bit-rock interaction: the axial-torsional coupling point at the bit. Three reduced models (see docs/derivation/bit-models.md); D = hole diameter, a = D/2, omega = bit speed, d = depth of cut per revolution.

coulomb – friction-dominated (worn bit / contact regime); 3 parameters:

TOB = mu_kinetic * WOB * D/3 sliding;  |TOB| <= mu_static * WOB * D/3 sticking
ROP = omega * WOB / (2 pi a S)

cutting – Detournay & Defourny (1992), quasi-static; 3 parameters:

WOB = W_f + S a d                    (contact threshold + cutting)
TOB = WOB a / (2 zeta)               (rate independent, no weakening)
ROP = omega * (WOB - W_f) / (2 pi a S)

regenerative – cutting with the depth of cut set by the hole-bottom profile left by the previous blade (Richard, Germay & Detournay 2007); 2 rock parameters + the blade count:

WOB = S a sum_j d_j,  TOB = WOB a / (2 zeta)

S = zeta * epsilon is the drilling strength (Pa); epsilon the intrinsic specific energy; zeta the ratio of normal to tangential cutting force.

Top-drive controllers (controllers)

Top-drive controller factories (Aarsnes, di Meglio & Shor 2018, Sec. 3).

All three industrial controllers share one block diagram: a PI speed loop, optionally with impedance feedback of band-pass filtered pipe torque. The factories compute gains from the drill-pipe characteristic impedance zeta_p = J_p sqrt(G rho) and the top-drive inertia.

Controllers that do not fit this structure can be written in Python and run in the simulator’s external-torque mode (see Simulation.step()).

Cell geometry (geometry)

Per-cell wellbore geometry used by both the torque & drag model and the dynamic simulator, so the two compute identical normal forces.

The soft-string normal force per unit length on a cell is

F_N = | T * dt/ds + w_b * z_perp |

where t is the unit tangent, T the effective tension, w_b the buoyed weight per length and z_perp the component of the downward unit vector perpendicular to the pipe. This vector form is equivalent to the Johancsik et al. (1984) expression and is valid for any change in azimuth (including crossing north) without special handling.

Steady torque and drag (statics)

Steady-state soft-string torque and drag (SI units).

Friction on each element opposes the sliding velocity of the pipe surface, which has an axial component v (positive downhole) and a tangential component omega * r. Rotation therefore reduces drag, the classic velocity-split model. Normal force uses the vector soft-string relation in DrillPyze.geometry and is updated with the local tension while integrating from the bit up (Johancsik et al. 1984; Sheppard et al. 1987).

Sign conventions

  • tension is effective tension, positive in tension. At the bit it is -WOB.

  • torque is the torque transmitted downward, positive in the rotation direction. At the bit it is TOB.

  • v > 0 is moving downhole (slack-off / RIH), v < 0 is pick-up.

Hydraulics (hydraulics)

Borehole hydraulics (SI units).

Steady state

Newtonian and Bingham-plastic pressure losses in pipe and annular flow, bit nozzle loss, standpipe pressure, bottomhole pressure and ECD, as in Shor, Introduction to Drilling Engineering, ch. 7 (Borehole Hydraulics):

* apparent viscosity: pipe  mu_a = PV + tau_y D / (6 v)
                      annulus mu_a = PV + tau_y (D2 - D1) / (8 v)
* Reynolds number:    pipe  Re = rho v D / mu_a
                      annulus Re = rho v 0.816 (D2 - D1) / mu_a
  laminar below 2100, turbulent (transition treated as turbulent) above
* laminar:   pipe     dp/dL = 32 PV v / D^2  + 16 tau_y / (3 D)
             annulus  dp/dL = 48 PV v / h^2  + 6 tau_y / h,       h = D2 - D1
             (slot flow, 12 PV v / g^2 + 3 tau_y / g with the gap g = h / 2)
* turbulent: Fanning, Blasius f = 0.0791 Re^-0.25 with Re on PV,
             dp/dL = 2 f rho v^2 / D_e,  D_e = D (pipe), 0.816 h (annulus)
* bit:       dp = rho Q^2 / (2 C_d^2 A_n^2)
* SPP = dp_surface + dp_string + dp_bit + dp_annulus;  BHP = p_hydrostatic + dp_annulus

(These are the chapter’s field-unit equations written in SI.) A Newtonian fluid is the special case tau_y = 0, PV = mu.

Transient

WellboreHydraulics – the single-phase limit of the drift-flux model of Wang, Khaled, Luu, Ashok & van Oort (2023, SPE-214836-MS; after Evje & Fjelde 2002): mass and momentum along the drillstring and annulus with rho(T, p) of their eq. 2, a volume-rate inlet, a constant-pressure outlet, fixed cells with volume-averaged cross sections, and the bit nozzles linking the two flow paths. See docs/derivation/hydraulics.md.

class DrillPyze.hydraulics.WellboreHydraulics(wellbore, grid, fluid, params, tfa, cd, bit_depth, hole_depth, bit_depth0)[source]

Transient single-phase drift-flux hydraulics of the circulating system.

Two flow paths on fixed cells (cell edges fixed in measured depth): the drillstring bore from surface to the bit, and the annulus (plus rat hole) from surface to the hole bottom. Cross sections are volume-averaged over the string occupying each cell (Wang et al. 2023, Fig. 1); the bottom annulus cell grows with the hole and the bottom drillstring cell follows the bit (grow-cut-grow, Fig. 2).

State: mass per cell (both paths) and mass flux per face. Pressure from rho(T, p) of Wang et al. eq. 2: p = c^2 (m/V - rho_T). Inlet: pump volume rate. Outlet: flowline at back_pressure. The bit nozzles are a face between the bottom drillstring cell and the annulus cell at the bit.

advance(t0, t1, ...) integrates with an explicit acoustic step on the pressures and a backward-Euler, Picard-iterated step on the face fluxes (friction, nozzle loss and Bingham yield stress implicit).

Wellbore temperature (thermal)

Transient wellbore temperature while drilling, after the modified drift-flux model of Wang, Khaled, Luu, Ashok & van Oort (2023), “Downhole Temperature Estimation of a Growing High-Temperature Wellbore Using a Modified Drift Flux Modeling Approach”, SPE-214836-MS, doi:10.2118/214836-MS.

Implemented here in its single-phase (liquid mud) form:

  • drillstring and annulus fluid energy balances on a common axial grid, upwind in the flow direction (paper eqs. 3-5, 13);

  • radial heat flow drillstring <-> annulus and annulus <-> formation through series conduction/convection resistances (eqs. 6-9; Nusselt number from Dittus-Boelter for turbulent flow, 3.66 for laminar flow);

  • the formation as radial conduction cells per axial cell with the undisturbed geothermal temperature in the far field (Khaled et al. 2023c);

  • a growing bottom cell, grown at the ROP and cut in two when it reaches a threshold (the “grow-cut-grow” strategy, Fig. 2), with the cuttings entering at the formation temperature (eqs. 14-20) and the bottom formation cells relaxed toward the undisturbed temperature as the hole deepens (eq. 10);

  • mud density rho(T, p) (eq. 2) integrated up the annulus with the frictional pressure loss to give the bottomhole pressure and ECD.

Simplifications relative to the paper, all consistent with its assumptions 1-3: single liquid phase (gas volume fraction zero), velocity from the pump rate (ROP << mud velocity), axial conduction in the fluid neglected, transient heat storage in the drillstring steel neglected, cuttings carry their heat into the mud at the bottom cell. Moving geometry discontinuities are handled by volume-averaging the string geometry over each cell at every update (Fig. 1); the associated ROP-scaled area-change terms of eqs. 11-13 are O(ROP/v) and omitted.

Units: SI, temperatures in deg C.

Formation and rock strength (formation)

Formation description and rock strength at the bit.

Rock strength enters the bit models through the drilling strength S = zeta * epsilon, with the intrinsic specific energy taken as the confined compressive strength at the bit divided by a cutting efficiency eta:

epsilon = CCS_eff / eta

CCS_eff combines three effects (see docs/derivation/rock-strength-and-temperature.md):

P1  Confinement by the overbalance, Mohr-Coulomb
        CCS = UCS + dp * (1 + sin phi) / (1 - sin phi)
    with dp = p_bh - p_p for permeable rock, and for low-permeability /
    low-porosity rock the undrained ("Skempton") pore pressure
        p_p* = p_p - B (sigma_v - p_bh) / 3
    blended by effective porosity (Caicedo, Calhoun & Ewy 2005; US 7,412,331
    and US 7,555,414).
T1  Thermal weakening of the rock
        UCS(T) = UCS_0 [1 - beta max(T - T*, 0)]
    fitted to granite data of Xu et al. (2019): T* = 193 C, beta = 1.41e-3 /K.
T2  Cooling-induced thermal stress at the hole bottom
        sigma_th = alpha E (T_rock - T_mud) / (1 - nu)
        CCS_eff  = CCS - kappa sigma_th min(1, delta / d_b)
    where delta = sqrt(pi D_th t_pass) is the thermal skin cooled between
    blade passes and d_b the depth of cut per blade.

Temperatures are in deg C, pressures in Pa, depths in m.

Simulator UI server (ui.server)

DrillPyze interactive UI server.

A small standard-library HTTP server that owns Simulation objects and steps them on request; the browser front end (static/) edits the case, drives the transport (play / pause / step) and animates the results.

Run with drillpyze-ui (or python -m DrillPyze.ui) and open the printed address. API (JSON over HTTP):

GET /api/defaults default case config (Well A) POST /api/init {config} build + initialise a simulation -> session, geometry, first frame POST /api/step {session, duration, inputs} advance and return one frame GET /api/results.csv?session=… all recorded channels (SI) as CSV
