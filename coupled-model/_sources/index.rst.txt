DrillPyze: coupled drillstring model
====================================

DrillPyze simulates the coupled axial–torsional dynamics of a drillstring in
real time: soft-string friction along the well path, bit–rock interaction,
top-drive controllers and an autodriller, circulating hydraulics, wellbore
temperature and rock strength at the bit. It includes an interactive
simulator UI with a driller's display and a browser version (DrillPyze Lite).

This documentation is built from the ``coupled-model`` branch.
